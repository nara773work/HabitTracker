# 詳細設計

## 目的・目標
習慣を記録し、継続日数を木の年輪として感覚的に振り返ることができるようにする。
目標日数ごとに木の種類が選択できるようにする（1年 = 1日換算とする）

【木の種類】
シラカバ-30日（約1か月）
スギ-90日（約3か月）
ウメ-100日
トチノキ-180日（約半年）
ケヤキ-365日（1年）
クスノキ-1000日

## フロント設計
### 画面イメージ
- index
それぞれの習慣を一覧表示する（1ページ最大4つまで）
→それぞれの習慣にゴミ箱マークを付け、deleteできるようにする。また、ペンマークをつけ編集できるようにする
新規作成ボタン（プラスボタン）
ステータス分けをし、完成した木も残す
2日以上スキップしてしまった木も残す→やり直す場合は元の灰色を上書きしていく。

- 各習慣ページ（詳細画面）
画面に表示するもの
習慣の名前（毎日5時に起きる、など）
できたボタン（押すと橙色の年輪が追加される）→10日ごとに茶色の年輪を入れる
年輪の絵
年輪の数字（継続日数）

- 編集画面
新しい習慣の入力欄
木の種類選択欄

※それぞれCRUD後は必ずメッセージ表記をすること
例）習慣を新規作成しました

### フロントの動作
- ボタンを押すと年輪が増える（前日以前は薄茶色、本日分は濃い茶色）
- ボタンを2回押すと取り消せる（24時を過ぎると確定する）
- 10日ごとにこげ茶の年輪にしてわかりやすくする
- 1日スキップはOKとする（ただし前日の年輪が灰色になる）→継続日数は引き継ぐ
- 2日以上スキップすると全体が灰色になり枯れる（最初からやり直しボタンに変更する）

## バック設計
### DB設計
- habits：習慣名を管理する
id:主キー
name（習慣名）
timing(行動を行うタイミング)
created_at
updated_at

- tree_types：木の種類と目標日数を管理する
id:主キー
name（木の名前）
target_days（目標日数）
sort_order

- habit_runs：木の成長を管理する（積み上げ日数と年輪数を管理）
id:主キー
habit_id
tree_type_id
ring_count(表示する年輪数)
started_on（開始日の日付）
restart_on（やり直しを始めた日付け）
recovery_count（灰色から通常色に戻した年輪の数）
status(completed,ongoing,withered)
updated_at

- habit_logs：達成日を管理する
id
habit_run_id
completed_on
attempt_number　→何回目の挑戦かを記録
created_at
updated_at

### リレーション
習慣:多--1:木の成長記録:1--1:木の種類
　　　　　　|
           |:1---多:達成日の管理

### 動作とDBの対応
- できたボタンを押すと、当日分のhabit_logsを1件追加する。（年輪と達成数が1つ増える）
- 24時までに取り消したらログも削除する。（年輪と達成数も戻す）
- スキップ日はログを追加しない。
- 1日空いた場合、年輪を灰色に変化させる
- 2日連続でスキップされた場合、habit_runs.statusをwitheredに変更する。
- スキップ後に復帰した際、灰色の年輪の色は戻さずに次の年輪が始まる
- 枯れた木をやり直す際はrestarted_onを今日の日付にし、recoery_count<元の年輪の数の間ログを再開せず色を戻す作業のみとする。

### コントローラー設計
- HabitController
習慣の新規作成、編集、更新、削除、できた・取り消すの操作

index
- 一覧表示（取組中のもののみ表示）→検索で完成木、失敗木も表示可能
- ページネート（4件ずつ）
- 木の種類
- 継続日数

show
- 木の描画
- 達成日数
- 達成ボタン

cretae
- 習慣の作成画面

store
- DBに習慣を保存する

edit
- 習慣の作成画面
- 習慣名は編集できない
→習慣名（行動）が編集できると後にややこしくなると思ったから。

delete
- 習慣の削除

toggle
- 本日の習慣の達成・未達成を変更する

## testでの動作確認
### feature（HabitController）
- 実行ボタンの挙動：habit_logができ、ring_countが増加する。もう一度押すとreing_countが減る。
- 日付を翌日に進めて実行する：前日ログを取り消さず、新しい日付のログが作成される
- 1日スキップした木を表示する：ステータスはongoingで年輪の色は灰色
- 2日連続でスキップした木を表示する：ステータスがwitheredになる
- 完成した木をスキップ状態で表示する：completed のままで、灰色化されない
- 枯れ木の育てなおすを押す：新しい挑戦としてリセットされ、今日のログが作られる
- 編集画面を表示する：	現在の木の目標日数以下の木だけ選択肢に出る
